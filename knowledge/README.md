# Knowledge

- `research/`: dated council and researcher reports, immutable once written, with per-claim model attribution. Raw material; not authoritative until adjudicated.
- `kb/` (planned v0.3): adjudicated claims only, structured for retrieval via a knowledge-base MCP server so sessions load single claims instead of whole files.

Rule: nothing graduates from `research/` into `kb/` or `memory/` without passing dealbreaker adjudication (verified or corroborated tier), and every claim carries its verification date.
