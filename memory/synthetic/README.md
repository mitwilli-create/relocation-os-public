# Synthetic twin (public-safe example data)

These files are the fictional twin of the real, gitignored `memory/private/`
corpus. They exist so the public portfolio cut can demonstrate the memory
schema and the gate machinery without exposing any real personal context.

Everything here is invented. The person, the constraints, the eliminated
cities, and the numbers are fictional and describe no real individual.

Mapping to the private schema:

- `personal-context.md` mirrors `memory/private/personal-context.md`
- `eliminators.txt` mirrors `memory/private/eliminators.txt` (registry L1)
- `mission-brief-2026-07-scouting.md` mirrors the private scouting brief

In the real system these live under gitignored `memory/private/` and are
restored per machine. To run the OS against this twin, copy these files into
`memory/private/` (see docs/USING-THE-OS.md). The public cut ships the twin as
tracked sample data and keeps `memory/private/` gitignored and empty, so the
quarantine pattern is shown, not hidden.
